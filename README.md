# astrbot_plugin_smart_reply ｜ 智能自动回复

![logo](logo.png)

不靠关键词。它让机器人在**合适的时机自己接一句话**：

- 每条消息先过触发范围（群 / 私聊开关、用户与群的白黑名单）；
- 再用消息**频次粗筛**——太冷清、正在刷屏都不打扰，也不花 token；
- 只有落在灰区的消息串才问一次模型「现在插话合适吗」；
- 同一串消息判过就复用结论，一个群不会反复问模型；
- 回复后没人接话就算被无视，连续被无视自动降频，有人接话立刻恢复。

只想在特定群生效：把 `group_target_mode` 设为 `whitelist`，把群号填进 `group_whitelist`，其余群完全不参与。

## 特性

- **纯语境驱动**：没有触发词表，机器人看聊天记录自己决定该不该开口
- **只在特定群生效**：白名单之外的群连消息都不统计
- **范围可控**：群与用户各自可选「不限制 / 仅白名单 / 仅黑名单」，黑名单优先级最高
- **先粗筛再问模型**：窗口内条数太少（冷清）或太多（刷屏）直接跳过，省 token
- **被点名直接回**：@机器人或唤醒词命中时不进粗筛，直接交给模型
- **同串消息只问一次**：指纹取最近若干条消息，TTL 内重复出现就套用旧结论
- **节流**：同一会话两次判断有最小间隔，两次自动回复之间有冷却
- **被无视就降频**：累计到阈值抬高门槛、按倍数拉长冷却（有上限），有人接话立即清零
- **保守优先**：模型报错、输出为空、解析不出来，一律判为「不回复」，宁可不打扰
- **回复不引用**：默认直接发送，绕过框架的引用装饰（只影响本插件发出的消息）
- **开关齐全**：总开关、群聊 / 私聊开关、忽略机器人自己的消息（防自问自答死循环）

## 工作流程

```
消息
 └─ 总开关 → 群聊/私聊开关 → 忽略机器人自己
     └─ 用户白黑名单 → 群白黑名单
         └─ 频次粗筛（可能被降频档位抬高门槛）
             ├─ 冷清（条数 < min_msgs）→ 不回复
             ├─ 刷屏（条数 > spam_msgs）→ 不回复
             ├─ 被点名（@机器人 / 唤醒词）→ 直接进入判断
             └─ 灰区 → 冷却检查 → 缓存查询 → 问模型 → 发送
```

判断用的提示词要求模型只输出一行 `YES` / `NO` / `YES|回复内容`；
读不出内容时用 `fallback_reply` 顶上，它留空就干脆不发送。

## 触发范围（白名单 / 黑名单）

群与用户各有独立一套，先选模式再填名单（逗号、分号、顿号、空格、换行、`+` 分隔都行）：

| 模式 | 行为 |
|---|---|
| `off`（默认） | 不做白名单限制，但黑名单依然生效 |
| `whitelist` | 只有白名单里的群 / 人才触发；**白名单为空则一律不触发** |
| `blacklist` | 黑名单里的群 / 人不触发，其他都触发 |

- 黑名单优先级最高：同时出现在两份名单里，按不触发处理。
- `ignore_user_ids` / `ignore_group_ids` 视为黑名单的一部分，旧配置照旧生效。
- 群聊消息要同时过用户与群两道校验，私聊只过用户一道。

## 窗口限次

`burst_window_seconds` 秒内自动回复最多 `burst_limit` 次，默认 120 秒 2 次，防止话头一多就一直插话：

- 统计范围只算**真正发出去的自动回复**，被点名回复也算在内，和冷却不同层级、同时生效；
- 冷却决定「隔多久才能再说」，限次决定「这段时间里一共能说几次」，先过冷却再看限次；
- 窗口是滑动的：最早那次回复出窗即释放额度，不用等整段窗口清零；
- 两项任一填 `0` 即关闭限次；手动指令触发与被点名直通不受限次影响。

## 被无视降频

回复后 `ack_seconds` 秒内没人接话，记一次「被无视」；连续达到 `ignore_limit` 次后开始降档：

- 粗筛门槛抬高：每档 `min_msgs + level_step × 档位`，越难进入灰区；
- 冷却拉长：`cooldown_seconds × backoff_base ^ 档位`，上限 `backoff_cap` 倍；
- 档位上限 `max_level`；只要有人接话，档位立刻清零。

## 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关，关闭后本插件完全不参与，连消息记录都不统计 |
| `enable_group` | `true` | 群里是否生效 |
| `enable_private` | `false` | 私聊是否生效（默认关闭，私聊一般不主动插话） |
| `ignore_bot` | `true` | 忽略机器人自己的消息，防死循环 |
| `group_target_mode` | `off` | 群聊触发范围：`off` / `whitelist` / `blacklist` |
| `group_whitelist` | `[]` | 群白名单，仅在 `whitelist` 模式下生效 |
| `group_blacklist` | `[]` | 群黑名单，任何模式下都生效 |
| `user_target_mode` | `off` | 用户触发范围：`off` / `whitelist` / `blacklist` |
| `user_whitelist` | `[]` | 用户白名单，仅在 `whitelist` 模式下生效 |
| `user_blacklist` | `[]` | 用户黑名单，任何模式下都生效 |
| `ignore_user_ids` | `[]` | 不触发的 QQ 号，等效于追加到用户黑名单 |
| `ignore_group_ids` | `[]` | 不触发的群号，等效于追加到群黑名单 |
| `no_quote` | `true` | 回复时不引用原消息（直接发送，绕过框架的引用装饰） |
| `window_seconds` | `120` | 频次统计的时间窗口（秒） |
| `min_msgs` | `3` | 窗口内条数少于这个数算冷清，不插话也不问模型 |
| `spam_msgs` | `0` | 窗口内条数达到这个数算刷屏；`0` 表示不判断刷屏 |
| `probe_msgs` | `12` | 问模型时附带最近几条消息，越少越省钱，推荐 8–15 |
| `cache_ttl` | `180` | 判断结果缓存时长（秒） |
| `cache_span` | `8` | 算缓存指纹时取最近几条消息 |
| `min_interval` | `20` | 同一会话两次问模型的最小间隔（秒），`0` 不限制 |
| `cooldown_seconds` | `120` | 两次自动回复之间的基础冷却（秒），会按档位放大 |
| `burst_window_seconds` | `120` | 限次窗口（秒），`0` 表示不启用限次 |
| `burst_limit` | `2` | 窗口内最多自动回复几次，`0` 表示不限次 |
| `ack_seconds` | `60` | 回复后多少秒没人说话算一次「被无视」 |
| `ignore_limit` | `2` | 连续被无视几次开始降频 |
| `max_level` | `4` | 最高降频档位 |
| `level_step` | `2` | 每升一档，粗筛门槛抬高几条 |
| `backoff_base` | `2.0` | 每升一档冷却乘这个数 |
| `backoff_cap` | `8.0` | 冷却倍数上限 |
| `reply_max_chars` | `120` | 自动回复最大字数，超出截断 |
| `fallback_reply` | 空 | 模型只回 `YES` 没给内容时用的话术，留空则不发送 |
| `judge_prompt` | 空 | 判断用提示词模板，可用 `{messages}` `{session}` |
| `judge_system_prompt` | 空 | 判断用系统提示词，留空用内置 |

## 常见配置

**只想在一个群里活跃**

```
group_target_mode = whitelist
group_whitelist   = ["123456789"]
enable_private    = false
```

**群里很热闹，怕它太吵**

```
min_msgs     = 6
spam_msgs    = 40
cooldown_seconds = 300
```

**想省 token**

```
probe_msgs   = 8
cache_ttl    = 600
min_interval = 60
```

## 目录结构

```
main.py            插件主体：消息监听、范围校验、粗筛、判断、发送
guard.py           纯逻辑：名单解析、触发范围校验、冷却记录（可离线测试）
context_judge.py   纯逻辑：频次粗筛、结论缓存、降频、提示词组装与解析（可离线测试）
_conf_schema.json  WebUI 配置 schema
metadata.yaml      插件元信息
tests/             离线单元测试（test_context_judge.py / test_guard.py）
```

## 测试

```bash
python3 tests/test_context_judge.py   # 频次粗筛 / 缓存 / 降频 / 解析 / 提示词
python3 tests/test_guard.py           # 名单解析 / 触发范围 / 冷却
```

## 说明

- 冷却、缓存、降频记录都只在内存里，插件重载或 AstrBot 重启即清空，不留痕。
- 判断调用使用独立的 session_id（`<会话>:smart-reply-judge`），不会污染机器人的正常对话记忆。
- 仅支持 `aiocqhttp` 平台，AstrBot 版本要求 `>= v4.12.0`。
